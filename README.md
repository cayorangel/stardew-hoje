# O Que Fazer Hoje em Stardew

Planejador diário para jogar Stardew Valley em co-op. Vocês preenchem o dia, o clima, a sorte, as habilidades, a fazenda e o Centro Comunitário, e a página sugere as missões de cada jogador, a rotina do dia, os itens dos pacotes que dá para conseguir hoje e o que plantar.

Acesse: https://cayorangel.github.io/stardew-hoje/

Tudo roda num único `index.html`. Os dados ficam salvos no próprio navegador (localStorage).
